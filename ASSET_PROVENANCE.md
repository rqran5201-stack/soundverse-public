# Public model provenance

On 2026-11-19 the project creator explicitly confirmed ownership/generation and authorization to publicly display the supplied Aholo/Lux3D models in the competition website.

Selected GLBs: starlight-tree (task 4830722), moon-mushrooms (task 4893490), user-supplied moon-ancient-tree, moon-tall-tree, moon-moss-rock and moon-ferns. The last three match the creator-supplied model directory. Texture images were reduced to 1024/512 pixels and opaque base colors encoded as JPEG. Geometry/UV/anchors are preserved; original files are retained privately. This confirmation permits project display; it does not grant downstream model reuse rights or an open asset license.

The public asset configuration allows only the six selected exports. Other models retain procedural fallback. Public instance counts are bounded. Loading an existing export does not create a paid generation task. No music, original lyrics, signed download URLs, tokens or private task journals are included.

Deferred: 432k-triangle wind-grass and shrub clusters; 269k-triangle coastal arch; reef/coral and tidepool scenery not needed for the P0 flow. Full AI world, rigged animal and controllable-avatar assets are not present in this release. Procedural terrain, water, distant trees, low-cost ground cover and fauna remain intentional runtime components.
